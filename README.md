# 🔍 XRAT - Open Source Intelligence (OSINT) Framework

> **XRAT** est un outil d'investigation et d'analyse OSINT (*Open Source Intelligence*) conçu pour regrouper, automatiser et structurer la recherche d'informations publiques provenant de sources ouvertes.

---

## 📌 À propos du projet

Inspiré par la structure et la philosophie d'outils d'analyse comme **Void Panel**, **XRAT** a été développé dans le but d'offrir une interface centralisée et fluide pour les chercheurs en cybersécurité, analystes SOC et passionnés d'OSINT.

L'objectif principal est de simplifier la collecte de données publiques (*Threat Intelligence*, vérification d'empreinte numérique) tout en garantissant un cadre clair et structuré.

---

## ✨ Fonctionnalités principales

- 🌐 **Agrégation de sources publiques :** Centralisation des recherches d'informations d'intérêt public.
- 📊 **Interface structurée :** Présentation claire et lisible des données collectées.
- ⚡ **Automatisation :** Gain de temps sur les requêtes manuelles répétitives.
- 🛡️ **Périphrase & Modularité :** Conçu pour intégrer facilement de nouveaux modules d'investigation.
